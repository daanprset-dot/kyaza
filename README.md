# Kyaza Inisial
1. Buat repo GitHub **public**, isi owner/repo/token di `js/config.js` (token fine-grained: Contents Read & Write, hanya repo itu).
2. Upload folder ini ke GitHub Pages / hosting statis (atau buka dengan Live Server).
3. Buka `admin.html`, login, klik "Tes Koneksi GitHub", lalu tambah produk.
Halaman: `index.html` (store), `dashboard.html`, `admin.html`. Logika di `js/main.js`.
